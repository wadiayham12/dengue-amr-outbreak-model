# Dengue & AMR Outbreak Model

A predictive epidemiological dashboard designed to simulate the correlation between seasonal Dengue spikes, environmental climate metrics, and subsequent trends in bacterial Antimicrobial Resistance (AMR) caused by empirical drug misuse.

## Mathematical Architecture
This repository implements algorithmic tracking to correlate:
*   **Environmental Vectors:** Monsoon rainfall surges and thermal boundaries in urban Dhaka.
*   **Epidemiological Curves:** Viral transmission rates ($R_0$) vs. secondary bacterial selection pressures.

## Usage
```bash
python dashboard_renderer.py
```
